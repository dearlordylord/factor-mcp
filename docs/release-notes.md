Factor Meals Canada SDK, MCP server and CLI, MIT licensed.

Includes 10 MCP tools for subscriptions, deliveries, menus, recipe ingredients, past meals, order history, selection previews and verified main-meal saves. Capture your own Factor session locally; no credentials or private account data are distributed.

Install all three tarballs with npm, as documented in the README. Each release includes SHA256SUMS. npm registry publication is separate.
